# Blackbeard GTK Themes
Dark and light GTK themes (GTK 2/3/4) for Arch Linux, designed to work with the blackbeard-nvim Neovim plugin.

## Installation
- Install via AUR: `yay -S blackbeard-gtk-themes`
- Apply with `lxappearance` or `blackbeard-nvim` (`:Blackbeard dark` or `:Blackbeard light`).

## Dependencies
- gtk2, gtk3, gtk4
- Recommended: papirus-icon-theme, nordzy-cursors
